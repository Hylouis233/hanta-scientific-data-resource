# Hantavirus research project

Secondary project in the `autoresearch` monorepo.

Working manuscript direction:

> Hantavirus host ecology, environmental drivers, and spatial spillover risk across Eurasia and the Americas

Initial focus:

1. Virus-host-region index.
2. GBIF rodent occurrence data plan.
3. HFRS/HCPS distinction and regional branches for China, Four Corners, and Andes virus.

Fixed evaluation entrypoint:

```bash
bash evaluation/evaluate.sh configs/experiment.yaml
```
