# Ebola source audit layer

This directory is the authority for Ebola Phase 1 source provenance.

Files:

- `sources.registry.yaml`: source metadata and intended role.
- `source_audit_log.csv`: audit status for each source.
- `field_dictionary.yaml`: canonical fields for processed outputs.
- `license_and_terms.md`: license and terms status.

Current status: M1 metadata registry. Source files have not been downloaded. Entries are not manuscript-ready until retrieval date, checksum, schema mapping, and license status are audited.

M1 acceptance requires at least two authority sources and source anchors. M2/M3 require actual raw files, checksums, and processed outputs.
