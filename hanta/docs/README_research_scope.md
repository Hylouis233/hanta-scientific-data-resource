# Hanta research scope

Hanta remains an incubator while Ebola is the main line.

The Hanta project focuses on host, environment, exposure, HFRS/HCPS distinction, and S/M/L segment genomics. It should not copy Ebola Rt or human-to-human transmission assumptions by default. Andes virus person-to-person transmission should be treated as a specific subcase, not the general Hantavirus model.
