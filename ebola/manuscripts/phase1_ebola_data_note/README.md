# Phase 1 Ebola data note

This manuscript unit is a data note / reproducible analysis note for source-audited Ebola outbreak time series.

Scope:

- West Africa 2014-2016 and North Kivu/Ituri 2018-2020 source curation.
- Descriptive comparison of reporting granularity, outbreak shape, source coverage, and data limitations.
- Rt estimation only after data quality gates pass.
- No causal attribution to individual interventions without a separate causal design.
