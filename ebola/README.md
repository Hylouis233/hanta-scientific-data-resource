# Ebola research project

Priority project for the `autoresearch` monorepo.

Working manuscript direction:

> Ebola virus disease transmission heterogeneity, outbreak control, and genomic epidemiology across Central and West Africa

Initial focus:

1. West Africa 2013–2016 as the primary transmission-dynamics dataset.
2. North Kivu DRC 2018–2020 as the next validation/comparison outbreak.
3. Global outbreak index for cross-outbreak comparison.
4. Later integration of genomic epidemiology and phylogeography.

Fixed evaluation entrypoint:

```bash
bash evaluation/evaluate.sh configs/experiment.yaml
```

Current status: ResearchOps scaffold only; no real data has been downloaded or analyzed.
