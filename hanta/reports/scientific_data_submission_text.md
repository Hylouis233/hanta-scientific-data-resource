Title: A claim-bounded public-data ResearchOps resource for hantavirus formal gate evaluation

## Data availability

Data records and generated reports are represented in DVC-bounded raw/processed directories and reviewer-facing manifests. The local deposition package is available at release/scientific_data_submission_package/ pending external repository deposition DOI. Credentials, local-only DVC configuration, private coordinates and sensitive individual-level human health data are not included.

## Code availability

All generation, validation, descriptor, audit and packaging scripts are stored under scripts/. The fixed project evaluation entrypoint is bash evaluation/evaluate.sh configs/experiment.yaml.

## Ethics and privacy

The resource uses public/self-service source data, aggregate surveillance records and a public supplementary animal trapping/testing table. It does not request personal identifiers or sensitive individual-level human health data. Coordinates excluded by source authors for private-land protection were not reconstructed or inferred.
