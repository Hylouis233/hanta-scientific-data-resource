# Phase 1 Ebola priorities

1. Build a source-audited West Africa 2013–2016 case time series.
2. Create a compact outbreak metadata table with country, administrative unit, dates, cases, deaths, viral species, and source references.
3. Implement validation checks for missing dates, inconsistent cumulative counts, and source conflicts.
4. Add preliminary literature parameter table for incubation period, serial interval, CFR, and R0/Rt estimates.
5. Only after source audit, add Rt estimation and intervention timing overlays.

No pipeline output should be described as a scientific finding until the relevant source rows are audited and marked as real data or literature parameters.
