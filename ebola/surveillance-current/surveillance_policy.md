# Current surveillance policy

Current Ebola surveillance data are mutable by default. They must not be mixed into the historical Phase 1 data lock unless an explicit data-freeze procedure is approved.

A current surveillance record is manuscript-eligible only after:

- source URL and retrieval date are recorded;
- raw file checksum or page snapshot hash is recorded;
- case definition and geography level are stated;
- report explicitly labels the data as rapidly evolving or final;
- the analysis branch is separate from historical West Africa/North Kivu analysis.
